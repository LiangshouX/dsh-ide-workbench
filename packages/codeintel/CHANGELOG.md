## 0.1.0

这一版是 **V6 插件拆分**的 codeintel 侧：从 `dsh-ide-workbench` 里搬出来的**代码智能**，
现在是一个**独立插件**。

### 它带来了什么

- **本地补全**：`.ts` 里敲 `fo` 出现候选。
- **语义补全 / 跳转定义 / 查找用法（语义 Alt+F7）/ 查找用法（文本 Alt+F8）/ 悬浮 / 签名提示**。
- **Ctrl+click 跳转**与 **Ctrl-hover 高亮**。
- **搜索弹层**（浮层式的查找，含上下文预览）。
- **Java / JDTLS**：Java 项目能起 jdtls 并答语义请求。
- **记忆预算**：机器级总预算、内存闸门、压力释放阀、空闲回收、崩溃恢复 ——
  **行为语义与拆分前逐条一致**（算式、状态机、请求预算口径一律未动）。
- **状态栏的「语义分析」格**与**设置页的「语言服务器」分组**。

### 它需要什么

- **需要 IDE 工作台插件 `dsh-ide-workbench`**（本插件的编辑器、状态栏、设置页都由它提供）。
- **只装 codeintel 时**：插件**能正常加载**，会给一条明确的引导（提示缺少 IDE 工作台），
  **不会**启动任何语言服务器，**不会**抛未捕获异常。
- **契约版本**：本插件要求契约 major 版本 ≥ 1；宿主侧工作台插件的版本更低时会**拒绝启用**
  并提示升级。

### 它自带的东西

- **自己的语言服务器依赖**：`typescript` / `basedpyright` / `yaml-language-server` /
  `typescript-language-server` —— 这是工作台变轻的主因。
- **自己的设置文件**：`<profile>/dsh-codeintel/settings.json`，装它时**一次性**从工作台
  的旧设置里导入记忆预算、空闲策略与索引记忆，升级后不丢。
- **自己的故障边界**：本插件的未捕获异常**留在本插件内**，**不杀 DSH 宿主**，
  **不掀翻工作台**。

### 它与工作台的边界

- 工作台**不知道**本插件的存在：没有 import、没有探测、没有依赖。
- **CodeMirror 运行时由工作台独占**，本插件通过契约与惰性代理取用 ⇒ 页面上只有一份
  `@codemirror/state`，编辑器的 `instanceof` 判定不会失效。
- **自动闭合括号两边都有**：双装时由本插件生效（优先级 100），工作台让位 ——
  **括号只闭合一次**，且**与插件加载顺序无关**。
