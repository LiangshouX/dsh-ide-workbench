# dsh-ide-codeintel

DeepSeek Harness 的**代码智能**插件：本地与语义补全、跳转定义、查找用法、悬浮与签名提示，
外加语言服务器（TypeScript / Python / Java-JDTLS / YAML）与它们的记忆预算。

> **需要 IDE 工作台插件 [`dsh-ide-workbench`](../workbench)**：本插件的编辑器、状态栏与设置页
> 都由工作台提供。**只装本插件时**，插件能正常加载，会给出明确的引导，**不会**启动任何语言
> 服务器，也**不会**抛未捕获异常。

## 装它能得到什么

| 能力 | 快捷键 / 入口 |
|---|---|
| 本地补全 | 打字即出（`.ts` 里敲 `fo`） |
| 语义补全 | 有语言服务器时出现服务端补全 |
| 跳转定义 | `F12` / Ctrl+click |
| 查找用法（语义） | `Alt+F7` |
| 查找用法（文本，标注「文本匹配」） | `Alt+F8` |
| 悬浮 / 签名提示 | 悬停 / 触发签名 |
| Ctrl-hover 高亮 | 按住 Ctrl |
| 查找用法弹层 | `Alt+F8` 的结果浮在工作台上，含上下文预览 |
| 状态栏「语义分析」格 | 就绪 / 休眠 / 保守版 / 启动中 |
| 记忆预算 | 设置页与诊断面板 |

> 全项目查找（`Ctrl+Shift+R`）由工作台自己提供，不是本插件的功能。

## 安装

```bash
dsh plugin --profile web add dsh-ide-codeintel
```

离线安装：Release 里的 `dsh-ide-codeintel-<版本>-offline.zip` 自带 `node_modules`（含语言服务器）
与安装脚本，解压后运行 `install-offline.ps1` / `install-offline.sh` 即可，不需要网络。

## 设置

本插件有**自己的设置文件**：`<profile>/dsh-codeintel/settings.json`，内容是记忆预算、空闲策略、
索引记忆与四个语义快捷键。首次启动时，它会**一次性**从工作台的旧设置文件里导入这些值，
升级后不丢。

## 与工作台的边界

- 工作台**不知道**本插件的存在（没有 import、没有探测、没有依赖）。
- **CodeMirror 运行时由工作台独占**，本插件通过契约与惰性代理取用 ⇒ 页面上只有一份
  `@codemirror/state`，编辑器的 `instanceof` 判定不会失效。
- **自动闭合括号两边都有**：双装时由本插件生效（优先级 100），工作台让位 —— 括号只闭合一次，
  且**与插件加载顺序无关**。
- 本插件的未捕获异常**留在本插件内**：不杀 DSH 宿主，不掀翻工作台。
