# PRD 与规格归档

本目录收纳**按版本演进的规格文档**。目录规则：**按版本号 V 分层**，同一版本的规格、配套记录、检视报告与进展记录放在一起。

> 归集于 2026-11-01。此前这些文档平铺在 `docs/` 根目录；归集时同步修正了全仓 **170+ 处路径引用**（含 `README.md` / `README_EN.md` / `src/` 注释 / `tests/` 夹具），归集本身不改变任何技术内容。

## 目录结构

```
docs/prd/
├── README.md              ← 本文件：索引与规则
├── v1/                    ← 第一版规格
├── v2/                    ← 第二版规格
├── v3/                    ← 第三版规格
├── v4/                    ← 第四版规格
├── v5/                    ← 第五版规格
├── v5.1/                  ← 第五版的修订轮（当前主线）
└── archive/               ← 无版本号的历史需求轮次记录
```

## 命名与收录规则

| 规则 | 说明 |
|---|---|
| **版本目录** | `vN/`，其中 `N` 与文档名里的 `PRD-vN` 一一对应 |
| **规格** | `PRD-vN.md` —— 该轮的**唯一规格**，实现以它为准 |
| **配套记录** | `PRD-vN-<主题>.md` —— 实施进展、缺陷跟踪、代码检视报告、复核记录 |
| **无版本号的轮次** | 放 `archive/`，并在文件头注明它属于哪一轮的前身 |
| **跨版本的长期文档** | **不**进本目录，留在 `docs/` 根（如 `VERIFICATION.md` 累计验收、`M0-api-findings.md` DSH API 契约） |
