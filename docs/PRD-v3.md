## 2. 范围

### M1 — 可信编辑器（本里程碑必须完成）

1. 新建文本标签默认进入编辑态（≤1MB），大文件只读；工具栏仍可切换。
2. 只读/编辑统一使用 CodeMirror 代码面；只读必须可拖选、`Ctrl+A`、`Ctrl+C`。
3. 插件自有 FindBar：
   - 只读与编辑同一套 UI；
   - 计数 `当前/总数`，大小写、整词、正则；
   - `Enter` / `Shift+Enter` / `F3` / `Shift+F3` 循环；
   - `Esc` 关闭；
   - 编辑态支持替换与全部替换；
   - 不出现英文默认面板或黑块按钮。
4. 关闭脏标签三选一：保存并关闭 / 放弃 / 取消。
5. 确认框默认焦点在“取消”，`Esc` 取消，`Enter` 不误确认危险操作。
6. 保存时携带读取到的 `mtimeMs`；磁盘已被外部修改则返回冲突，不覆盖。
7. 回滚已暂存文件后 `git status` 必须干净。
8. 删除：回收站失败不得静默永久删除；二次确认后才可永久删除。
9. 文件树打开态与选中态分离；树内 `Ctrl+A` 只选树节点。
10. 终端切换面板/对话后保留 scrollback 与 PTY 会话。

### M2 — 搜索与 Git

1. `Find in Files` 标签：`Ctrl+Shift+F`，按文件分组，显示命中数与耗时；点击定位到行。
2. 快速打开：`Ctrl+Shift+N` / `Ctrl+P`，模糊匹配路径，`Enter` 打开。
3. 树过滤：
   - 文件模式默认走全项目索引，扁平结果；
   - 树模式保留，但只过滤已加载目录，并显示明确提示，不再伪造“加载中”。
4. Git：
   - 日志占满剩余高度；详情从右侧 Drawer 出现；
   - 宽屏分栏（默认 420px，可拖 340–60%，按工作区持久化）；窄屏覆盖式；
   - 单击只选中；双击 / `Enter` 打开 Drawer；`Esc` 关闭；
   - 筛选变化后清理不在列表中的选中项；
   - 分支切换与分支筛选合并为一个无重复的控件组；
   - 脏工作区阻止 checkout；
   - `[` 等查询字符不导致 git 报错（固定字符串匹配）；
   - 增加日期预设筛选。
5. 分支默认显示当前分支，筛选默认“全部分支”。

### 非目标

- 结构性过滤、日期之外的复杂过滤。
- Changelist 重命名/拖拽。
- 多根工作区、远程 Git 图形化操作。
- 重写 Diff 虚拟化渲染器。

## 3. 交互契约

### 3.1 FindBar

```
┌ 查找 ──────────────────────────────────────────────┐
│ [查询............] 3/17  ↑ ↓  [Aa] [ab] [.*]  ×   │
│ [替换............]  替换  全部替换                  │  ← 仅编辑态
└────────────────────────────────────────────────────┘
```

- `Ctrl+F` 打开并全选查询；再次 `Ctrl+F` 不重复打开。
- 无结果时输入框显示错误色，计数 `0/0`。
- 正则非法时保留输入、显示错误，不抛异常。
- 只读态不显示替换行。

### 3.2 Git Drawer

```
┌ Git ──────────────────────────────────────────────────────────┐
│ [当前分支 ▾] [分支筛选 ▾] [作者] [搜索] [日期 ▾] [刷新]        │
│ ┌ 日志（全高） ───────────────────────┐ ┌ Drawer 420px ────┐ │
│ │ ● ...                               │ │ sha 复制 ×        │ │
│ │ ● ...                               │ │ 作者/时间/parents │ │
│ │                                     │ │ 文件列表 + 内联 diff│ │
│ └─────────────────────────────────────┘ └──────────────────┘ │
└───────────────────────────────────────────────────────────────┘
```

- Drawer 非模态；宽屏点日志不关闭。
- Drawer 内文件单击 = 内联预览；双击 = 打开该文件完整 diff 标签。
- 关闭 Drawer 后焦点回到触发的提交行。

### 3.3 文件树状态

- 选中：`--itw-selection` 蓝色背景。
- 打开：左侧 2px 强调条 + 文件名强调色；不再使用同一背景色。
- 二者可同时存在于不同行，语义可区分。

## 4. API 增量

| 方法 | 请求 | 返回 |
|---|---|---|
| `fs.files` | `{ root }` | `{ files: string[], tookMs }` |
| `fs.search` | `{ root, query, caseSensitive?, wholeWord?, regexp?, include?, exclude?, maxResults? }` | `{ files: [{path,matches:[{line,column,preview}]}], truncated, tookMs }` |
| `fs.write` | 增加 `expectedMtimeMs?` | 冲突时 `code=stale-file` |
| `fs.delete` | 增加 `allowPermanent?`（默认 false） | 回收站失败返回 `code=trash-failed`，不删除 |
| `git.log` | 增加 `since?` | 原结构 |
| `git.checkout` | 不变；客户端先检查脏工作区 | — |

## 5. 验收

### 搜索

- [ ] 只读打开文本 → `Ctrl+F` → 输入 → 计数正确 → `Enter`/`Shift+Enter`/`F3` 循环 → `Esc` 关闭。
- [ ] 只读拖选 / `Ctrl+A` / `Ctrl+C` 得到完整文本。
- [ ] 编辑态替换、全部替换后 dirty 正确。
- [ ] `Ctrl+Shift+F` 在 10k 文件仓库首屏 < 500ms；点击结果定位到行。
- [ ] `Ctrl+Shift+N` / `Ctrl+P` 输入 3 字符结果即时；`Enter` 打开。
- [ ] 树过滤在折叠仓库输入文件名能命中；树模式明确提示“仅已加载”。

### Git

- [ ] 270px 高：日志至少 5 行；Drawer 打开后日志不塌陷。
- [ ] 单击只选中；双击/`Enter` 打开；`Esc` 关闭且焦点回行。
- [ ] Drawer 宽度可拖、重启后保留；窄屏为覆盖式。
- [ ] 分支控件不重复；脏工作区 checkout 被阻止；失败显示真实 stderr。
- [ ] 查询 `[` 不报错；日期筛选结果与 CLI 一致。

### 数据安全

- [ ] 关闭脏标签出现三选一；取消不丢修改。
- [ ] 外部修改后保存返回冲突，不覆盖。
- [ ] 已暂存文件回滚后 `git status` 干净。
- [ ] 回收站失败时不静默永久删除。
- [ ] 确认框 Enter 不误确认，Esc 取消。

## 6. 实施顺序

1. Host API + 单测（files/search/stale-write/delete/log）。
2. 编辑器（默认可编辑、CodeMirror 只读、FindBar）。
3. 搜索 UI（Find in Files、快速打开、树过滤）。
4. Git Drawer 与分支/日期。
5. 树高亮、Ctrl+A、确认框、关闭三选一、回滚/删除。
6. 终端持久化。
7. 构建 + 单测 + 实机验收 + 截图。
